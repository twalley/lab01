Описание проекта
В данной лабораторной работе реализован пакет toolkit, состоящий из двух независимых консольных утилит:
1. Калькулятор — выполняет математические вычисления строк произвольной сложности (включая отрицательные числа и приоритет скобок) с использованием обратной польской нотации (ОПН).
2. Конвертер — универсальный инструмент для перевода физических величин между различными системами измерения (масса, длина, температура).

Структура проекта и описание файлов:
lab01/
    src/
       toolkit/
            __init__.py
            __main__.py      # точка входа для CLI (обработка команд calculator/converter)

            converter.py     # логика конвертации физических величин и температур
    tests/
            __init__.py
            test_calculator.py   # тесты для калькулятора
            test_converter.py    # тесты для конвертера

Инструкция по установке и запуску:

Все команды необходимо выполнять в виртуальном окружении из корневой директории lab01.

1. Настройка окружения
Если окружение еще не создано, выполнить:
cmd: python -m venv .venv

Активировать его (для винды):
cmd .venv\Scripts\activate

2. Локальная установка пакета
Установить проект в режиме редактирования, чтобы утилиты были доступны из любой папки:
cmd: pip install -e .

3. Примеры запуска утилит

Запуск калькулятора:
cmd: python -m toolkit calculator "12-3*(31-1)"

Запуск конвертера:
cmd: python -m toolkit converter 100 --from c --to k

Тестирование проекта:

Для запуска тестов используется pytest. Написанные тесты проверяют как стандартные успешные сценарии, так и сложные случаи (например, синтаксические ошибки в выражениях, деление на ноль или температуру ниже абсолютного нуля).

Запустить проверку всех тестов:
cmd: python -m pytest

Про help:
1. cmd: python -m toolkit --help
2. cmd: python -m toolkit calculator -h
3. cmd: python -m toolkit converter -h
